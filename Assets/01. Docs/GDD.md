# 보스 레이드 게임 기획서 (통합본)

---

## 1. 게임 개요

**한 줄 소개:** 망자가 된 사냥꾼이 마을의 화톳불에서 준비하고, 거대한 화룡을 사냥하고, 그 소재로 강해져 다시 도전하는 1인 보스 레이드 액션.

| 항목 | 내용 |
|---|---|
| 장르 | 3D 3인칭 보스 레이드 액션 |
| 플레이 | 1인, PC (키보드 · 마우스) |
| 엔진 | Unity, 3인칭 락온 카메라 |
| 구성 | 마을과 보스 투기장. 보스 하나를 단계별로 사냥 |
| 아트·애니메이션 | 보유 에셋 사용 (직접 제작 없음) |
| 개발 기간 | 10/21 ~ 11/04 (1인, 주말 포함) |
| 발표 | 11/04 |
| 목표 플레이 시간 | 30~40분 |
| 레퍼런스 | 몬스터헌터, 다크소울 |

시스템은 몬스터헌터에서(실력 + 준비, 부위파괴, 보스 소재로 장비 제작), 다크소울에서(소울 드랍, 인간성) 가져옵니다. 몬헌의 친목(4인 협동)이 빠진 자리를 다크소울의 **잃을 것을 들고 싸우는 긴장**이 채웁니다.

| | 몬스터헌터 | 다크소울 | 우리 게임 |
|---|---|---|---|
| 핵심 미학 | 도전, 친목, 판타지 | 도전, 판타지 | 도전, 감각 |
| 이기는 방법 | 실력 + 준비 | 실력 | 실력 + 준비 |
| 긴장의 원천 | 3번 죽으면 실패 | 소울을 잃을 수 있음 | 소울과 사람 상태를 잃을 수 있음 |
| 성장 | 소재 → 장비 | 레벨업 | 소재 → 장비, 인간성 → 회복약 |

### 디자인 원칙

1. **레벨은 없다.** 성장은 장비, 인간성, 식사로만 한다. 실력을 수치로 밀어붙이지 못하게.
2. **모든 죽음은 다음 판의 준비가 된다.** 준 피해와 얻은 소재는 죽어도 남는다.
3. **억까가 있어도 버틸 수 있게.** 대부분의 공격은 예비동작을 보고 구르기, 가드, 태클, 상쇄 중 잘 맞는 대응을 고를 수 있지만, 모든 공격에 깔끔한 답을 두지는 않는다. 피하기 어려운 공격은 회복약, 인간성, 방어구로 버틸 수 있게 하고, 한 방에 죽는 공격은 두지 않는다.
4. **새 시스템은 하나씩 연다.** 첫 판은 공격, 구르기, 회복약만으로 싸울 수 있다.
5. **코어 루프부터.** 매 개발 단계가 끝날 때마다 처음부터 끝까지 플레이할 수 있어야 한다.

## 2. 플레이어 경험 목표

> **"지난 판에 나를 죽인 보스의 공격을, 다음 판엔 준비한 장비와 익힌 손으로 받아친다."**

죽음 → 준비 + 연습 → 받아침.

- **지난 판에 나를 죽인** → 잃을 것을 들고 싸우는 긴장
- **준비한 장비** → 준비가 곧 플레이
- **익힌 손** → 보스를 읽는 사냥
- **받아친다** → 강해짐의 확인 (위협이 기회로 바뀜)

### 한 판의 경험

1. **화톳불, 고민:** 무엇을 먹을지, 인간성을 쓸지, 소울을 쓰고 갈지 들고 갈지
2. **안개문, 긴장:** 모아둔 소울을 들고 투기장에 들어간다
3. **교전 초반, 압박:** 보스의 공격을 피하기 바쁘다
4. **전환:** 물기를 상쇄로 받아치자 보스가 휘청이고, 결국 지쳐서 브레스가 불발된다
5. **해방:** 그 틈에 풀차지를 모아 내려치고, 꼬리가 잘려나간다
6. **귀환, 다음 목표:** 얻은 소재로 무엇을 만들지 생각한다


### MDA

**A — 미학**

| 구분 | 미학 | 이 게임에서의 모습 |
|---|---|---|
| 핵심 | 도전 | 실력과 준비, 두 축으로 보스를 푸는 것 |
| 핵심 | 감각 | 대검 한 방의 무게, 상쇄의 충격, 부위가 깨지는 순간 |
| 보조 | 표현 | 무기 갈래, 호석·요리 조합으로 만드는 나만의 공략 |
| 보조 | 발견 | 보스의 습성, 지쳤을 때의 신호를 알아가기 |

친목(1인 플레이)과 서사(텍스트는 확장으로 미룸)는 목표에서 뺍니다.

**D — 다이나믹스**

| 다이나믹스 | 플레이 중에 생기는 일 | 출처 |
|---|---|---|
| 준비가 곧 플레이 | 2단계의 화염 장판을 보고 화룡 세트·심장 찜·화염 저항 호석으로 대비한다. "꼬리뼈 대검을 만들려면 꼬리 가시가 필요해" → 이번 사냥은 꼬리를 노린다 | 몬스터헌터 |
| 보스를 읽는 사냥 | 예비동작을 보고 대응을 고른다. 브레스가 불발되면 지친 것 → 몰아친다. 원하는 부위를 골라서 때린다 | 몬스터헌터 |
| 잃을 것을 들고 싸우는 긴장 | 모아둔 소울을 들고 들어간다. 떨어진 소울을 회수하러 뛴다. 인간성을 지금 쓸지 아껴서 태울지 고민한다. 회복약이 3~5개뿐이라 마실 때마다 판단한다 | 다크소울 |
| 강해짐의 확인 | 구르기 바빴던 물기를 상쇄로 받아친다. 새 장비로 1단계 보스를 빠르게 잡는다. 다음 단계가 열린다 | 둘 다 |

**M — 메커닉**

| 메커닉 | 만드는 다이나믹스 |
|---|---|
| 스태미나, 보스 예비동작 | 보스를 읽는 사냥 |
| 대검 차지, 태클, 가드, 상쇄 | 보스를 읽는 사냥, 강해짐의 확인 |
| 보스 스태미나와 피로 | 보스를 읽는 사냥 |
| 부위파괴 | 준비가 곧 플레이, 보스를 읽는 사냥 |
| 소울 드랍과 회수 | 잃을 것을 들고 싸우는 긴장 |
| 인간성 | 잃을 것을 들고 싸우는 긴장, 준비가 곧 플레이 |
| 장비 제작 | 준비가 곧 플레이, 강해짐의 확인 |
| 보스 단계 (1단계 → 2단계) | 강해짐의 확인 |
| 요리, 호석 | 준비가 곧 플레이 |

요리와 호석은 보조 미학(표현)에만 걸려 있습니다. 호석은 개발이 밀리면 가장 먼저 확장으로 넘기고(빠져도 핵심 미학은 유지), 요리는 꼭 넣습니다.

### 플레이테스트 질문

| 질문 | 성공 신호 | 실패 시 의미 |
|---|---|---|
| 지난 판에 죽었던 공격, 이번 판엔 어떻게 했어? | 장비, 요리, 상쇄 이야기가 나옴 | 경험 목표 미달 |
| 출격 전에 뭘 고민했어? | 인간성, 식사, 소울 사용 고민 | 준비 축이 약함 |
| 제일 손에 땀 쥔 순간은? | 소울 회수, 인간성 사용 | 긴장 축이 약함 |
| 처음엔 무서웠는데 나중엔 반가웠던 공격 있었어? | 특정 패턴을 이름으로 말함 | 상쇄·태클 보상이 약함 |

## 3. 코어 루프

**화톳불에서 준비 → 보스 사냥 → 보상 → 대장간에서 제작 → 다시 준비.** 한 바퀴는 약 5~7분(준비 1분, 전투 3~5분, 제작 1분)이라 죽어도 바로 다시 들어갈 수 있습니다.

```
 [화톳불: 준비] ──▶ [안개문] ──▶ [투기장: 사냥] ──┬─ 처치 ──▶ 보상(소울·소재·인간성) ─┐
       ▲                                         └─ 사망 ──▶ 준 피해만큼 소울 + 얻은 소재 ┤
       │                                              (들고 간 소울은 투기장에 드랍)    │
       └──────────────── [대장간: 제작·강화] ◀─────────────────────────────────────┘
```

죽어도 준 피해만큼의 소울과 얻은 소재는 남기 때문에, 실패한 판도 다음 판의 준비가 됩니다. 잃는 것은 들고 온 소울과 사람 상태뿐이고, 둘 다 다음 판에 투기장에서 회수할 수 있습니다.

### 세 겹의 루프

| 루프 | 내용 |
|---|---|
| 전투 루프 (초 단위) | 예비동작을 읽는다 → 공격에 맞는 대응을 고른다 → 틈에 치거나 차지를 모은다 → 스태미나를 보고 거리를 잰다 |
| 사냥 루프 (분 단위) | 화톳불에서 준비 → 사냥 → 보상 또는 사망 → 대장간에서 제작 |
| 진행 루프 (게임 전체) | 1단계 첫 처치 → 뿔·꼬리를 노리는 재사냥으로 무기 갈래와 화룡 세트 → 2단계 해금 → 화염에 막힘 → 방어구·요리·호석으로 대비해 돌파 |

## 4. 전투

무기는 대검 하나입니다. 회피 수단이 하나면 모든 공격의 답이 같아지므로, 대응 수단의 역할을 나눠 **공격마다 잘 맞는 대응이 다르게** 합니다. 다만 모든 공격에 깔끔한 답이 있지는 않습니다. 피하기 어려운 공격은 회복약, 인간성, 방어구로 버티는 것까지가 공략입니다.

- **구르기:** 큰 공격, 가드할 수 없는 공격을 피한다
- **가드:** 안전하지만 스태미나가 깎이고 밀려난다
- **태클:** 가벼운 공격을 버티면서 차지를 이어간다
- **상쇄:** 특정 공격을 정면으로 받아친다. 위험하지만 보스를 크게 지치게 한다

### 플레이어 기본값

- HP 100, 스태미나 100 (행동을 멈추고 0.6초 뒤 초당 35 회복)
- 회복약 3개로 시작, 1개당 HP 50, 마시는 1.2초 동안 무방비. 마을에 돌아오면 자동 보충
- 레벨 없음. 수치는 장비, 인간성, 식사, 호석으로만 바뀜

### 대검 액션

| 행동 | 입력 | 스태미나 | 효과 |
|---|---|---|---|
| 차지 콤보 (3타) | 좌클릭 (홀드로 차지) | 타당 25 | 몬스터헌터 대검 방식 (모아베기 → 강 모아베기 → 참 모아베기). 약공격·강공격 구분 없이 **모든 타가 차지 공격**. 누르면 칼을 들고(Windup), 누르고 있으면 버티며 차지(Hold), 떼면 내려침(Release). 짧게 누르면 0단계로 내려침. 적중 여부와 관계없이 다음 타로 이어짐 |
| 태클 | 차지 중(Windup·Hold) 우클릭 | 25 | 0.4초 슈퍼아머, 받는 피해 −50%. 끝나면 그 타의 Hold로 복귀. 차지 단계 보너스 없음. 대기 상태에서는 사용 불가. **차지 한 번에 한 번만** |
| 가드 | Ctrl 홀드 | 막은 피해만큼 | 받는 피해 −80%, 밀려남. 스태미나 0이면 가드 붕괴 |
| 구르기 | Space | 20 | 무적 0.25초, 후딜 0.3초 |
| 상쇄 베기 | 좌클릭 + 우클릭 (공격 중이 아닐 때 0.1초 안에 함께 누르고 있다가 떼기) | 30 | 0.3초 판정. 상쇄 가능한 공격에 맞으면 보스 스태미나 −30, 경직, 머리 부위 대미지. 실패하면 피해를 그대로 받음 |
| 회복약 | R | 0 | HP 50 회복 |
| 락온 | 휠 클릭 | 0 | 카메라가 보스 고정 |
| 달리기 | LeftShift 홀드 | — | 대기·이동 중에만 |

### 행동 전환

대기 상태에서는 태클을 뺀 모든 행동을 바로 쓸 수 있습니다. 행동 중에는 아래 표에 있는 행동으로만 넘어갈 수 있고, 나머지는 그 행동이 끝나 대기로 돌아온 뒤에 가능합니다.

| 현재 행동 | 넘어갈 수 있는 행동 | 비고 |
|---|---|---|
| 대기 | 좌클릭, 가드, 구르기, 상쇄 | 태클 불가 |
| 차지 콤보 — Windup | 태클 | |
| 차지 콤보 — Hold | 태클, 구르기 | |
| 차지 콤보 — Release | 다음 타 (입력 창 안에서만) | 구르기·태클 불가 |
| 가드 중 | 좌클릭, 구르기 | 누르는 즉시 전환 |
| 태클 후 | 좌클릭, 구르기, 가드 | |
| 상쇄 후 | 좌클릭, 구르기 | |
| 구르기 | 없음 | 후딜까지 끝나야 다음 행동 |

- 피격은 위 표와 관계없이 모든 행동을 끊습니다.
- 차지 중 우클릭은 태클입니다. 상쇄는 공격 중이 아닐 때 두 버튼을 0.1초 안에 함께 눌러야 나갑니다. 좌클릭을 살짝 먼저 눌러 Windup이 시작됐더라도 0.1초 안에 우클릭이 들어오면 상쇄로 바꿉니다.

### 차지 단계

| 단계 | 조건 | 대미지 배율 | 비고 |
|---|---|---|---|
| 0 | 1단계 도달 전에 뗌 (Windup 중 포함) | ×1.0 | |
| 1 | 0.5초 | ×1.3 | |
| 2 | 1.0초 | ×1.5 | |
| 3 | 1.5초 | ×1.8 | |

- 차지 시간은 **누른 순간부터** 잽니다 (Windup 시간 포함).
- 단계는 **버튼을 뗀 순간** 확정합니다. Windup 중에 떼도 Windup은 끝까지 재생한 뒤 내려치지만, 단계는 뗀 순간의 값(0단계)입니다.
- 단계가 오를 때마다 빛·소리 연출
- 태클은 단계를 올리지 않음. 태클 중에도 차지 타이머는 계속 흐름
- 3단계 위로는 오르지 않음 (과충전은 미결정 사항 참고)

### 타별 차이

단계 배율은 모든 타가 공유하고, 타마다 기본 계수를 곱합니다. 뒤로 갈수록 강하지만 길고 무겁습니다.

| 타 | 기본 계수 | 비고 |
|---|---|---|
| 1타 | ×1.0 | 내려베기 |
| 2타 | ×1.2 | |
| 3타 | ×1.5 | 콤보 마무리. 끝나면 콤보 초기화 |

- 최종 피해 = 무기 공격력 × 타 계수 × 단계 배율 (수치는 초기값, 테스트하며 조정)
- 이전 타의 Release 후반(입력 창)에 다시 누르면 다음 타의 Windup으로 이어집니다. 창이 닫히면 1타로 초기화합니다.

### 공격 종류별 대응

보스 패턴마다 아래 태그 중 하나를 붙입니다. 표의 **최선**은 가장 잘 맞는 대응이고, 그 외의 "가능"으로도 버틸 수는 있습니다.

| 태그 | 예시 | 구르기 | 가드 | 태클 | 상쇄 |
|---|---|---|---|---|---|
| 가벼운 공격 | 앞발 할퀴기 | 가능 | 가능 | **최선** (차지 유지) | 불가 |
| 상쇄 가능 | 물기 | 가능 | 가능 | 불가 | **최선** (보스 스태미나 크게 감소) |
| 가드 불가 | 앞발 내려찍기, 착지 | **최선** | 붕괴 | 불가 | 불가 |
| 화염 | 브레스 | **최선** (옆으로 빠지기) | 가능 (스태미나 크게 소모) | 불가 | 불가 |

- 불가인 대응을 쓰면 일반 피격으로 처리합니다.
- 상쇄 가능한 공격은 2단계까지 **물기 하나만** 둡니다. 상쇄할 공격이 분명해야 배우는 맛이 살아납니다.

### 억까 패턴과 버틸 수단

- 피하기 어려운 공격(넓은 화염 장판, 연속 공격 등)도 일부 둡니다. 모든 공격을 완벽히 피하게 만들려고 패턴을 깎지 않습니다.
- 대신 **한 방에 죽지 않게** 합니다. 공격 한 번의 피해는 맨몸 최대 HP의 60%를 넘지 않게 잡습니다 (초기값).
- 맞았을 때 회복할 틈을 줍니다. 큰 공격 뒤에는 회복약을 마실 수 있는 틈을 둡니다.
- 버틸 수단은 회복약(인간성을 태워 늘림), 인간성 사용(전투 중 전회복), 방어구(피해 감소)입니다. 억까 패턴이 이 시스템들을 쓸 이유가 됩니다.

### 대검의 무게감

에셋 모션(Powerful Sword Pack)이 대검치고 빠르므로, 전체를 늦추지 않고 구간별로 속도를 다르게 줍니다.

| 구간 | 속도 | 목표 길이 |
|---|---|---|
| 준비 (칼을 드는 부분) | 느리게 | 0.4~0.6초 |
| 내려치기 | 원래 속도 또는 살짝 빠르게 | — |
| 후딜 (칼이 박히고 다시 드는 부분) | 느리게 | 0.6~0.8초 |

공격은 **루트 모션으로 앞으로 내딛으며** 칩니다 (In Place 아님).

### 타격감 (Feel)

- 히트스탑: 차지 0~2단계 0.05초, 차지 3단계 0.1초, 상쇄 0.15초
- 카메라 쉐이크, 타격 이펙트(Sword slashes PRO), 타격음
- 상쇄 성공: 불꽃 + 금속음 + 0.3초 슬로모션
- 부위파괴: 파편 이펙트 + 보스 휘청임 + 화면 가장자리 플래시

## 5. 보스

보스는 **하나를 단계로 나눠** 씁니다. 모델과 모션을 재사용하고, 단계마다 수치·색·패턴 한두 개만 바꿉니다.

**사용 에셋(후보):** Heroic Fantasy Creatures Full Pack Vol 1의 **용**. 확인된 공격 모션은 좌발, 우발, 물기, 불뿜기, 불 흩뿌리기 5개입니다. 아래 패턴은 이 5개 기준이며, 비행·돌진·꼬리 공격처럼 **모션 유무가 확인 안 된 것은 "모션 확인"으로 표시**했습니다.

| 단계 | 이름 | HP | 공격력 | 역할 |
|---|---|---|---|---|
| 1단계 | 미정 | 1500 | ×1.0 | 패턴을 배우는 벽. 지상 패턴만 |
| 2단계 | 미정 | 2400 | ×1.3 | 준비를 요구하는 벽. 붉은 색, 화염 장판, (비행) |
| 3단계 (확장) | 미정 | — | — | 모든 패턴 + 비행 2페이즈, 날개 파괴 |

### 1단계 패턴

| 패턴 | 사용 모션 | 예비동작 | 태그 | 대응 | 틈 | 보스 스태미나 |
|---|---|---|---|---|---|---|
| 물기 | 물기 | 고개를 뒤로 젖힘, 0.6초 | 상쇄 가능 | 상쇄 / 구르기 | 1.0초 | −10 |
| 앞발 할퀴기 | 좌발 또는 우발 (좌→우 2연타 분기 가능) | 앞발을 옆으로 당김, 0.5초 | 가벼운 공격 | 태클 / 구르기 | 0.8초 | −10 |
| 앞발 내려찍기 | 좌발/우발 클립의 준비 구간을 느리게 + 착지 충격파 이펙트 | 앞발을 높이 들고 멈춤, 0.8초 | 가드 불가 | 구르기 | 1.5초 | −20 |
| 화염 브레스 | 불뿜기 | 고개를 높이 들고 숨을 들이켬, 1.0초 | 화염 | 옆으로 빠지기 | 2.0초 | −25 |

앞발 내려찍기는 새 모션 없이 **같은 모션 + 다른 정보(속도·이펙트·소리)**로 만든 패턴입니다. 할퀴기와 내려찍기의 차이(발을 얼마나 높이 드는지)를 읽는 것이 실력이 됩니다.

### 2단계 추가 패턴

| 패턴 | 사용 모션 | 예비동작 | 태그 | 대응 | 틈 | 보스 스태미나 |
|---|---|---|---|---|---|---|
| 화염 흩뿌리기 | 불 흩뿌리기 | 고개를 옆으로 돌리며 숨 들이킴, 1.0초 | 화염 | 빠지기. 바닥에 불이 5초 남음 | 2.0초 | −25 |
| 비행 후 착지 | 비행 (**모션 확인**) | 날개를 크게 펼침, 2초 체공 | 가드 불가 | 착지 직전 구르기 | 2.5초 | −30 |
| 돌진 | 달리기 빠르게 (**모션 확인**) | 몸을 낮추고 땅을 긁음, 0.8초 | 가드 불가 | 옆으로 구르기 | 1.5초 | −20 |

- 비행 모션이 없으면 비행 패턴은 자르고 화염 흩뿌리기만 둡니다.
- 2단계의 화염 장판은 **맨몸으로는 버티기 힘들게** 수치를 잡습니다. "불 때문에 죽네"를 느끼는 순간 화룡 세트·심장 찜·화염 저항 호석이 답으로 보여야 합니다.

### 보스 스태미나와 피로

- 보스 스태미나 100. 패턴마다 소모(위 표), 상쇄당하면 −30, 초당 2씩만 회복
- 0이 되면 **피로 상태 15초**
  - 브레스 불발: 입만 벌리고 연기가 피식, 2초 굳음 → 플레이어에게 보내는 신호
  - 내려찍기 후 혼자 넘어짐 (3초 다운)
  - 이동 속도 −30%
- 피로가 끝나면 스태미나 100으로 회복
- 목표: 잘 피하고 받아치기만 해도 한 판에 2~3번 피로가 오게
- 피로·다운 전용 모션이 없으면 기존 모션 속도를 늦추거나 피격 모션을 길게 재생해서 표현

### 부위파괴

| 부위 | 내구도 | 잘 들어가는 것 | 파괴 효과 | 확정 소재 |
|---|---|---|---|---|
| 뿔 (머리) | 300 | 상쇄(+50), 차지 3단계 | 3초 경직, 물기 사거리 감소 | 뿔 1 |
| 꼬리 | 250 | 차지 1단계 이상만 절단 가능 | 3초 다운 (꼬리 공격 모션이 있으면 범위 감소) | 꼬리 고기 1, 꼬리 가시 1 |

- 부위 내구도는 사냥마다 초기화됩니다.
- 파괴로 얻은 소재는 **그 판에 죽어도 받습니다.**
- 모델에서 뿔·꼬리가 별도 본(bone)으로 나뉘어 있어야 부위별 히트박스를 붙일 수 있습니다.
- 패턴이 바뀌는 부위파괴(등 비늘 → 2페이즈, 날개 → 비행 추락)는 확장으로 미룹니다.

### AI 규칙

- 상태머신(Behavior Designer): 대기 → 거리 판단 → 패턴 선택 → 예비동작 → 실행 → 틈 → 대기
- **같은 시작동작에서 분기:** 고개를 뒤로 젖히면 물기, 거기서 더 높이 들면 브레스. 앞발을 당기면 할퀴기, 높이 들면 내려찍기
- **플레이어를 읽는 가중치:** 옆·뒤에 2초 이상 붙으면 몸을 돌리며 할퀴기 확률 증가, 멀리 있으면 브레스(2단계는 돌진) 증가, 회복약·인간성을 쓰면 브레스
- 같은 패턴 2연속 금지
- 패턴 하나 = 애니메이션 + 히트박스 활성 구간 + 태그 + 틈 + 스태미나 소모를 담은 데이터(ScriptableObject). 2단계는 이 데이터 묶음을 바꿔 끼우는 것으로 만듭니다.

## 6. 자원과 죽음의 규칙

자원은 소울, 소재, 인간성 세 가지입니다. 죽었을 때 **잃는 것은 "들고 있던 소울"과 "사람 상태"뿐**이고, 그 판에 해낸 것(준 피해, 부위파괴)은 남습니다.

| 자원 | 얻는 곳 | 쓰는 곳 | 죽으면 |
|---|---|---|---|
| 소울 | 보스 처치, 준 피해 | 무기·방어구 강화, 호석, 요리 재료 | 들고 있던 양이 투기장에 떨어짐 |
| 소재 | 처치 보상, 부위파괴, 체력 구간 달성 | 무기, 방어구, 호석, 요리 | 절대 안 잃음 (인벤토리) |
| 인간성 | 단계별 첫 처치, 부위파괴 10% | 사용(사람 상태) 또는 태우기(회복약 +1) | 가진 것은 안 잃음. 사람 상태만 잃음 |

### 소재와 역할

보스가 하나라 소재 종류가 적습니다. 한 소재를 모든 시스템이 달라고 하면 고민이 아니라 정체가 되므로, **주 용도 하나 + 경쟁 용도 하나**만 둡니다.

| 소재 | 출처 | 주 용도 | 경쟁 용도 |
|---|---|---|---|
| 화룡 비늘 | 1단계 처치 3~4개, 체력 25/50/75% 달성 시 1개씩 | 방어구 | 무기 갈래 |
| 뿔 | 뿔 파괴 | 용뿔 대검 | 파괴의 호석 |
| 꼬리 가시 | 꼬리 절단 | 꼬리뼈 대검 | — |
| 꼬리 고기 | 꼬리 절단 | 요리 | — |
| 분노 비늘 | 2단계 처치 3~4개 | 무기 +1 강화 | 맞부딪침의 호석 |
| 화룡 심장 | 2단계 처치 20% | 요리(심장 찜) | — |

### 처치 보상

| 단계 | 소울 | 소재 | 첫 처치 |
|---|---|---|---|
| 1단계 | 400 | 화룡 비늘 3~4 | 인간성 1, 2단계 해금 |
| 2단계 | 700 | 분노 비늘 3~4, 화룡 심장 20% | 인간성 1 |

### 죽었을 때

1. 이번 판에 **준 피해 비율만큼 소울**을 받음 (처치 보상의 최대 60%)
2. 이번 판에 부위파괴·체력 구간으로 얻은 **소재도 받음**
3. **원래 들고 있던 소울은 죽은 자리에 떨어짐**
4. 사람 상태와 식사 효과가 사라지고 망자로 돌아감 (화면이 창백해짐)
5. 다음 판 투기장에서 떨어진 소울을 주우면 소울 + 마지막 사람 상태와 식사가 돌아옴
6. 회수 못 하고 또 죽으면 떨어진 소울의 **절반은 화톳불로** 돌아오고 나머지는 사라짐

소울을 잃는 사람은 **모아둔 사람뿐**입니다. 매번 다 쓰고 들어가면 잃을 게 없고, 비싼 장비나 호석을 사려면 모아야 합니다. 그래서 용뿔 대검·방어구·호석 가격은 **두세 판은 모아야 살 수 있게** 잡습니다.

## 7. 성장

레벨은 없습니다. 가장 큰 성장은 플레이어의 손이고, 게임 안의 성장은 그 손을 돕는 세 갈래뿐입니다. 장비는 피격 한두 번의 여유를 줄 뿐, 패턴을 모르고도 이기게 만들지 않습니다.

| 성장 | 무엇으로 | 지속 | 플레이어의 선택 |
|---|---|---|---|
| 실력 | 패턴을 익히는 것 | 영구 (플레이어) | 어떤 공격에 무엇으로 대응할지 |
| 장비 | 보스 소재·부위파괴 소재 + 소울 | 영구 | 받아치는 무기와 몰아치는 무기 중 어느 갈래로 갈지, 그러려면 어느 부위를 노릴지 |
| 인간성 | 보스 첫 처치, 부위파괴 | 쓰면 한 판, 태우면 영구 | 지금 사람이 되어 강해질지, 화톳불에 태워 회복약을 영원히 늘릴지 |
| 준비 | 요리, 호석 | 한 판 | 이번 사냥을 어떤 방식으로 풀지 |

### 성장의 리듬: 문제가 먼저, 장비가 답

| 단계 | 역할 | 플레이어가 느끼는 문제와 답 |
|---|---|---|
| 1단계 | 패턴을 배우는 벽 | "이 공격을 어떻게 피하지?" → 실력과 첫 장비 |
| 2단계 | 준비를 요구하는 벽 | "불 때문에 버틸 수가 없네" → 화염에 강한 방어구, 요리, 호석 |
| 3단계 (확장) | 모든 것을 시험하는 벽 | 비행과 2페이즈, 날개 부위파괴 |

### 무기: 대검 하나, 갈래 둘

| 무기 | 공격력 | 특수 효과 | 비용 |
|---|---|---|---|
| 철 대검 | 30 | — | 시작 무기 |
| 철 대검 +1 | 34 | — | 소울 200 |
| 철 대검 +2 | 38 | — | 소울 400 |
| 용뿔 대검 | 44 | 머리 부위 대미지 +30%, 상쇄 성공 시 보스 스태미나 추가 −15 | 소울 800, 뿔 1, 화룡 비늘 4 |
| 꼬리뼈 대검 | 44 | 차지 단계 도달 시간 −20% | 소울 800, 꼬리 가시 1, 화룡 비늘 4 |
| 각 갈래 +1 | 52 | 같음 | 소울 1000, 분노 비늘 3 |

- 용뿔 대검은 **받아치는 사냥꾼**, 꼬리뼈 대검은 **몰아치는 사냥꾼**을 위한 갈래입니다.
- 갈래 무기의 재료가 부위파괴 소재라서, "이번 사냥은 뿔을 노린다"는 목표가 자연스럽게 생깁니다.
- 모션은 모두 같고 외형과 수치만 다릅니다.

### 방어구: 세트 단위

| 방어구 | 효과 | 비용 |
|---|---|---|
| 망자의 넝마 | 없음 | 시작 장비 |
| 화룡 비늘 세트 | 받는 피해 −15%, 불 피해 −30%, 브레스 가드 시 스태미나 소모 −30% | 소울 900, 화룡 비늘 8 |
| 화룡 비늘 세트 +1 | 받는 피해 −20%, 불 피해 −40% | 소울 1200, 분노 비늘 4 |

방어구는 생존, 호석은 플레이 스타일로 역할을 나눕니다.

### 인간성

하나를 얻을 때마다 **지금 강해질지, 영원히 강해질지** 고릅니다.

| 쓰는 법 | 어디서 | 효과 |
|---|---|---|
| 사용 | 언제든 (전투 중 포함, 1.5초 무방비) | HP 전부 회복 + 사람 상태(최대 HP +25). 죽을 때까지 유지 |
| 태우기 | 화톳불 | 회복약 최대치 영구 +1 (3개 → 최대 5개) |

- 사람 상태: 화면 톤이 따뜻해지고 캐릭터에 혈색. 망자 상태: 채도가 빠진 창백한 화면. 후처리 값만 바꿈
- 2주 버전에서 얻을 수 있는 양은 약 3~5개. 회복약을 끝까지 늘리면 사람 상태는 거의 못 쓰고, 사람 상태에 쓰면 회복약이 적은 채로 싸우게 됨

### 요리

생존(HP)은 인간성과 방어구가 맡으므로, 요리와 호석에는 HP 효과를 넣지 않습니다.

- 화톳불 옆 **냄비 하나**. NPC 없음. 기본 재료도 냄비에서 소울로 삼
- 출격 전 **한 끼만**. 효과는 사냥 한 번 동안
- 이기고 돌아오면 끝. 죽으면 사라지고, 떨어진 소울을 회수하면 돌아옴
- 식사 스킬은 **레시피마다 고정** (랜덤 아님)

기본 재료: 거친 빵(소울 30), 마른 고기(소울 50), 들풀(소울 20)

| 요리 | 재료 | 효과 | 언제 열리나 |
|---|---|---|---|
| 들풀 죽 | 빵 + 들풀 | 스태미나 회복 속도 +15% | 처음부터 |

## 8. 계속 플레이하게 만드는 장치

"한 판만 더"를 만드는 것은 세 가지입니다. 져도 남는 것, 되찾아야 할 것, 다음에 노릴 것.

| 장치 | 어떻게 | 플레이어의 생각 |
|---|---|---|
| 져도 남는다 | 준 피해만큼의 소울과 얻은 소재는 죽어도 받는다 | "이번 판도 헛수고는 아니었어" |
| 되찾으러 간다 | 들고 있던 소울과 사람 상태는 투기장에 떨어진다. 두 번 연속 죽어도 절반은 돌아와서 막히지는 않는다 | "내 소울 주우러 바로 다시 간다" |
| 다음 목표가 보인다 | 원하는 무기 → 필요한 부위 → 이번 사냥에서 노릴 곳이 정해진다 | "이번엔 꼬리를 자른다" |
| 같은 보스, 다른 싸움 | 노리는 부위, 무기 갈래, 요리와 호석 조합이 매번 다르다 | "이번엔 받아치는 걸로 해볼까" |
| 강해진 게 보인다 | 예전에 도망치던 공격을 받아치고, 새 장비로 예전 보스를 빠르게 잡는다 | "내가 진짜 늘었네" |
| 다음 벽이 열린다 | 첫 처치로 다음 단계 보스가 해금된다 | "저건 또 어떻게 잡지?" |
| 한 판이 짧다 | 몇 분짜리 사냥이라 다시 들어가는 부담이 적다 | "딱 한 판만 더" |

## 9. 마을과 시스템 공개 순서

마을은 걸어다니는 메뉴입니다. 사람이 거의 없는 쓸쓸한 광장에 오브젝트 다섯 개를 두고, 다가가서 [E]로 상호작용합니다. 보스를 잡을 때마다 등불이 하나씩 켜집니다.

| 오브젝트 | 기능 | 열리는 시점 |
|---|---|---|
| 화톳불 | 저장, 회복약 보충, 인간성 사용·태우기, 호석 교체 | 처음부터 (인간성은 첫 처치, 호석은 2단계 해금) |
| 안개문 | 사냥할 단계 선택 → 투기장 | 처음부터 (2단계는 1단계 처치 후) |
| 대장간 | 무기·방어구 제작과 강화, 호석 제작 | 첫 처치 |
| 냄비 | 재료 구입, 요리 | 2단계 해금 |
| 허수아비 | 가드, 태클, 상쇄 연습 | 처음부터 |

| 시점 | 새로 보이는 것 | 안내 방식 |
|---|---|---|
| 첫 도전 | 공격, 구르기, 회복약 | 조작 안내 한 줄. 가드·태클·상쇄는 허수아비 앞에서 |
| 첫 사망 | 소울 드랍 | "소울을 투기장에 두고 왔다" 알림 하나 |
| 첫 부위파괴 | 소재 | 파괴 연출 + 획득 표시 |
| 첫 처치 | 대장간, 인간성 | 화톳불에서 인간성 쓰는 법 안내 |
| 2단계 해금 | 냄비, 호석 | 불 때문에 고생하는 시점에 "이걸로 대비하라"는 도구로 등장 |

요리와 호석이 마지막에 열리므로, 1단계 경험은 이 둘 없이도 완성됩니다. 개발이 밀리면 호석은 빠질 수 있고, 요리는 꼭 넣습니다.

## 10. 구현 메모 (Unity)

### 전체 구조

- **버프 목록 하나로 계산:** 최대 HP, 스태미나, 차지 속도, 불 저항 등은 처음부터 **버프들의 합**으로 계산. 장비·인간성·요리·호석이 모두 "버프 하나 추가"로 끝나야 요리·호석을 나중에 붙이기 쉬움
- **보스 패턴 = ScriptableObject:** 애니메이션 + 히트박스 활성 구간 + 태그 + 예비동작 길이 + 틈 + 스태미나 소모. 단계별로 패턴 묶음을 바꿔 끼움
- **공격 태그 판정:** 플레이어 대응(구르기/가드/태클/상쇄)과 보스 공격 태그 조합으로 결과를 결정하는 함수 하나 (4장 대응 표 그대로)

### 차지 콤보 (3타)

한 타의 흐름은 모두 같고, 타마다 다른 건 데이터뿐입니다. 로직 하나를 3번 재사용합니다.

```
[Move] --누름--> [Windup] --누르고 있음--> [Hold 반복] --뗌--> [Release]
                    └--Windup 중에 뗌: Windup 끝까지 재생 후--┘
[Release] --입력 창 안에서 누름--> 다음 타의 [Windup]
[Release] --창 닫힘 / 클립 끝--> [Move], 콤보 1타로 초기화
```

- **클립 자르기:** 내려치는 클립을 타마다 임포트 설정에서 **Windup / Hold / Release** 세 개로 자름 (3타 × 3 = 9개, 우선 1타만)
  - Windup → Hold: Exit Time 자동 전환
  - Hold: Loop 켬 (2~5프레임, 살짝 떨리는 느낌)
  - Release: 코드에서 `CrossFade`로 넘김
- **차지 단계는 애니메이션이 아니라 코드 타이머** (`stageTimes = {0.5, 1.0, 1.5}`, `stageMultipliers = {1.0, 1.3, 1.8, 2.5}`)
  - 타이머는 누른 순간 시작, 단계는 **떼는 순간 확정**해서 저장
  - Windup 중에 떼면 `releaseQueued` 플래그만 세우고, Windup이 끝나는 시점에 Release로 넘김
- **입력:** `GetMouseButtonDown`(Windup 시작 / 다음 타 예약), `GetMouseButton`(차지 유지), `GetMouseButtonUp`(단계 확정)
- **콤보 입력 창:** Release 클립 뒷부분에 애니메이션 이벤트 `ComboOpen` / `ComboClose`. 창이 열린 동안 누르면 다음 타 예약
- **타별 데이터는 배열로:** `[Serializable] class ComboStep { Windup/Hold/Release 상태 이름, 타 계수, 스태미나 }`를 배열로 두고 인스펙터에서 조절. 코드에 `if (combo == 1)` 분기를 만들지 않음
- Animator 전환 화살표보다 **코드에서 CrossFade로 직접 넘기는 방식**
- `Animator.speed = 0`으로 멈추는 방식은 쓰지 않음 (전체 레이어가 멈추고 타이밍 버그)
- 구간별 속도(준비 느리게/내려치기 빠르게/후딜 느리게)는 State의 Speed로

### 태클

- 차지 중(Windup·Hold) 우클릭 → `Tackle` CrossFade, 끝나면 그 타의 Hold로 복귀
- 차지 한 번에 한 번만 (`tackleUsed`), 스태미나 소모
- 단계 보너스 없음. 차지 타이머는 태클 중에도 계속 흐름
- 태클 중 손을 떼면 입력을 기억했다가 태클 끝 프레임에 Release로 연결 (추천, 미확정)

### 루트 모션

- 공격은 `Apply Root Motion` 켜고 앞으로 내딛음
- **각 타의 Hold만** Root Transform Position(XZ) Bake Into Pose → 차지 중 미끄러짐 방지
- `OnAnimatorMove`에서 보스와 거리가 일정 이하면 전진량 0 (보스 관통 방지)
- 락온 중이면 **공격 시작 순간에만** 보스 방향으로 회전, 휘두르는 도중엔 회전 잠금

### 에셋 임포트 주의

- Malbers 계열 프리팹 Light 참조 경고는 Unity가 자동 수정, 무시 가능
- 분홍색 머티리얼 = 렌더 파이프라인 불일치 → URP 머티리얼 변환
- 에셋 스크립트가 컴파일 에러를 내면 스크립트는 빼고 모델·애니메이션만 사용

## 13. 발표 이후 확장

새 모션이 필요 없는 것부터 합니다.

1. 버퍼에서 빠진 것: 호석, 화덕·귀환의 호석
2. 3단계: 모든 패턴 + 비행 2페이즈, 날개 부위파괴(깨면 비행 중 추락)
3. 패턴이 바뀌는 부위파괴: 등 비늘을 깨면 2페이즈로 전환
4. 분노 상태: 평상 → 분노 → 피로 세 상태의 리듬
5. 텍스트와 분위기: 소재 설명에 사연, 처치마다 바뀌는 마을 모습
6. 두 번째 보스: 그리핀·만티코어 등 같은 팩에서 후보 선정
7. 무기 추가: 다른 모션 세트가 필요하므로 마지막
