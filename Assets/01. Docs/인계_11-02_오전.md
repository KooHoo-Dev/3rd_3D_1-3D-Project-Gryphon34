### A. 2단계 에디터 마무리 (확인 끝)
- `AirSpreadFire` 이벤트 이름 실수: Name `HitboxOn(AirFlame)` → **Name `HitboxOn` + Parameter `AirFlame`** (`Attack.ReceiveAnimEvent`는 이름이 정확히 `"HitboxOn"`일 때만)
- `PlayerBurn` Burn Time 10, `FX_Fire_01` Play On Awake 끔(루트·Embers 둘 다, 씬 오버라이드를 프리팹에 Apply), Burn Effect = `FX_Fire_01` 루트
- 상태 자식 `AirFireBallState`(`AirFireBall`), `AirSpreadFireState`(`AirSpreadFire`): `AirLand`, 0.92, Hover 2, Count 1, Land Move 1.3, Max 15
- 히트박스 `AirFlame`: `Head` 뼈 밑, `BreathHit` 복사 (위치·회전 그대로), id `AirFlame`, Fire, Rage Fire 끔
- 불줄기(Flame)·소리는 **브레스 것을 같이 씀** (복제 아님). 방향을 바꿔야 하면 파티클은 꼭 복제해서 (안 그러면 지상 브레스도 바뀜)
- 헷갈린 점: `BossState` 밑엔 **상태**만, `AirFlame`은 **히트박스**라 뼈 밑. 상태는 `GetComponentsInChildren<BossStates>()`로 찾아서 **켜 둔 채로**

### B. 공중 패턴 범위
| 고른 것 | 선택지 | 결정 |
|---|---|---|
| 공중 불덩이 범위 | 20~45m(멀면 무조건 날아옴, 반복 가능) / **겹치게 섞기** | **15~21m ±40°** (공중 흩뿌리기 10~21m ±40°) |
- 이유: `ChaseState`는 맞는 패턴이 하나라도 있으면 Decide → 20~45m에 공중 불덩이 하나뿐이면 멀리 있을 때마다 날고, 착지는 최대 15m만 다가와서 반복됨
- 결과(정면): 10~15m = 점프 물기·브레스·공중 흩뿌리기, 15~21m = 브레스·공중 2개, 21m~ = 걸어옴. 30~40° 옆 15~21m은 공중만 (브레스 ±30°)
- 정정: 패턴 번호 10 = 물기(5~9m), 11 = 점프 물기(10~15m), 12 = 브레스, 13 = 불덩이(도망 20~45m)

- 새벽 결정 "패턴 묶음 = Boss 배열(기본 + 단계 추가)"의 **변경** → 전/후로 기록
- 파일: `DecideState.cs`(`fromStage`, `AllPatterns`가 `boss.StageNumber`로 거름, 플레이 전 기즈모는 전부), `Boss.cs`(`StageNumber`), `StageValue.cs`(`extraPatterns` 삭제)

### F. 보스 예비동작만 느리게
| 고른 것 | 선택지 | 결정 |
|---|---|---|
| 방법 | 칸 Speed만 낮춤(휘두르기도 느려짐) / **예비동작만** | 애니메이터 Float `AttackSpeed` + 칸 Speed Multiplier |
| 구간 | **시작 ~ 첫 HitboxOn 자동** / WindupOn·Off 이벤트 | 2연타는 첫 타 앞만 |
- 파일: `States/Attack.cs`(`windupSpeed` 기본 1, `Enter`에서 낮춤, 첫 `HitboxOn`·`Exit`에서 1, 1이면 파라미터 안 건드림)
- 에디터 ✅: `AttackSpeed` 파라미터, Multiplier = `Bite`, `ClawsAttackLeft/Right`, `ClawsAttack2HitComboForward`, `TurnClawLeft/Right_Claw`. 값: 물기 0.55, 할퀴기 0.7, 2연타 0.7, 뒤 돌아 할퀴기 1, 점프 물기 1
- 기준: 예비동작 = 원래 시간 ÷ windupSpeed (물기 0.33초, 할퀴기 0.56초, GDD 목표 물기 0.6 / 할퀴기 0.5)
- 주의: 예비동작 동안 계속 플레이어 쪽으로 돎(더 오래 쫓아옴). 코드에서 `Animator.speed`는 쓰지 말 것 (히트스탑이 1로 되돌림)

### G. 상쇄·태클 뺌 → 퍼펙트 가드가 보스 피로도 깎음
| 고른 것 | 선택지 | 결정 |
|---|---|---|
| 상쇄·태클 | 유지 / 완전 삭제 / **입력만 막고 코드는 `#region 안 쓰는 것`으로 구석에** | 나중에 다듬을 수 있게 |
| 퍼펙트 가드 | 그대로 / **보스 피로도 깎음** | `perfectGuardFatigue` (상쇄 −10 대신) |
- 파일: `LocomotionState`(좌클릭 = 그냥 공격), `ChargeState`(차지만, 태클·상쇄 전환은 region 함수), `PlayerController`(Counter·Tackle 칸·함수·상태 등록 → region, `RegisterCounterTackleStates` 안 부름, Guard에 `perfectGuardFatigue`), `Boss.cs`(`Countered` → `ReduceFatigue`), `GreatSword`(상쇄 이펙트 → region), `CounterState`·`CounterCollider`(맨 위 "안 씀" 주석). region마다 다시 켜는 방법 주석
- 애니메이터는 안 건드림 (상쇄·태클 칸은 남아 있고 갈 길만 없음)
- 퍼펙트 가드는 막을 수 있는 공격 전부(브레스 포함)에서 깎음. 불덩이 폭발은 보스 밑이 아니라 안 깎임 (`info.Source`에 `Boss`가 없음)
