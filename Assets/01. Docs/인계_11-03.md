## 나와 일하는 방식 (중요 — 꼭 지키기)
- **항상 한국어로.**
- 학습 프로젝트라 **코드는 기본적으로 내가 짬.** 내가 "너가 해 / 구현해 줘"라고 한 **그 조각만** 짜기 (다음 조각까지 넘어가지 말 것)
- 맡겨도 **새 클래스·파일을 만들거나 기존 코드를 바꾸기 전에** 무엇을 만들고 무엇을 바꿀지 먼저 말하고 승인받기
- **값(수치)은 절대 마음대로 정하지 말기.** 선택지를 보여 주고 내가 고름
- 새 함수·클래스를 내가 짤 때는 **목표와 쓸 수 있는 값만 알려 주고, 내가 먼저 순서도/의사 코드를 쓰게** 하기 → 질문으로 리뷰
- "왜 ~해?"라고 물으면 **이유를 바로** 답하기 (되묻지 말 것)
- 설명은 짧고 단계별로. 큰 설명을 한꺼번에 주면 힘듦. 내가 "해 볼게, 어디부터?"라고 하면 **시작점 + 완료 기준만**
- **에디터 작업은 내가 함** → 어느 오브젝트·어느 화살표(들어오는/나가는)·어느 칸·무슨 값·그 값이 무슨 뜻인지까지 **정확하게.** 대충 말하면 다시 물어봐야 함
- 코드 리뷰는 전체 코드를 다시 쓰지 말고 **줄 위치를 짚어서** 설명
- 값 확인용 임시 화면 표시(OnGUI) 좋아함 — 테스트에 숫자가 필요하면 제안해도 됨
- **작업기록**: 한 덩어리 끝날 때마다 `작업기록.md`에 이어 쓰기 (지금은 19-x). 형식은 기존과 같게 — 고른 것/선택지/결정 표, 파일/바뀐 것 표, 에디터 작업 체크박스, 테스트. **누가 했는지 표시 금지** (이모지·"누가" 칸·AI 언급 X)
- 이름 규칙: 이벤트 = `On`+일어난 일, 핸들러 = `Handle`+무엇
- 커밋은 내가 직접. **6e3821e6 이후 것 전부 아직 커밋 안 됨**

## 작업 요령 (도구)
- 프리팹·애니메이터·씬 YAML은 통째로 읽지 말고 grep/perl로 필요한 것만 (Python 없음). 애니메이터 확인은 스크립트로 칸 이름·태그·화살표 조건·Exit Time을 뽑아서
- 컴파일 확인: 프로젝트 루트에서 `Assembly-CSharp.csproj` → `TmpCheck.csproj` 복사 → `dotnet build TmpCheck.csproj -nologo -v q` → `TmpCheck.csproj` 지우기 (새 .cs가 csproj에 아직 없으면 `<Compile Include=…>` 줄 추가)
- 문서(.md·.tsv)는 CRLF. .cs는 그 파일의 기존 줄바꿈 그대로

## 구조 요약 (자주 건드리는 것)
- **보스**: `Boss`가 상태 머신 (`ChangeState` → 상태 자식 오브젝트 `SetActive` + `Enter`, 애니 트리거는 상태의 `AnimatorTrigger`). 애니 이벤트는 `AnimStateEventSender`(칸에 붙음) → `AnimStateEventListener` → `Boss.HandleAnimEvent` → `CurrentState.ReceiveAnimEvent`. 공격 상태는 `Attack` 상속 (`HitboxOn/Off`, `RotateOn/Off`, `Sound`, `Effect` 이벤트). 상태 끝 = `BossStates.Update`가 애니메이터가 내 칸(이름/태그 = `animatorStateName`)에서 `exitTime`을 넘거나, 내 칸에 들어갔다가 빠져나가면 `OnAnimationEnd`. 패턴 선택은 `DecideState`(거리·각도 표)
- **플레이어**: `PlayerController`가 애니메이터 칸 태그로 상태(`PlayerStatesBase` 자식들: Locomotion/Charge/Attack/Dodge/Guard/Hit/Drink…)를 고름 (전환 중이면 다음 칸 기준). 피격은 `PlayerHealth.TakeDamage` 한 곳 → `TryGuard`. 칼은 `GreatSword`(슬래시·가드 이펙트·소리), 장비·요리는 `PlayerLoadout`
- **흐름**: 마을 `FogGate`(안개문, `stage` 1/2) → 투기장 `HuntManager`(처치/사망 → 보상·마을 복귀). 진행 저장 `GameData.Current` (`stage1Cleared` 등)
- 상쇄·태클은 11/02에 뺐음 (코드는 `#region 안 쓰는 것`으로 남음)
